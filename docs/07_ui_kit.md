# UI Kit: Camera Slider Controller

**Платформа:** ESP32-S3 + ST7735 160×128 (1.8", RGB565, SPI)
**Библиотека:** LovyanGFX (лучше TFT_eSPI по DMA и Sprite на S3) + Sprite double-buffering
**PSRAM:** рекомендуется — даёт полный двойной буфер (160×128×2 = 40KB) без артефактов

---

## 1. Цветовая система

**Контекст использования:** в помещении под студийным освещением (softbox). Приоритет — красота и информативность, а не максимальный контраст. Высококонтрастный режим существует как опциональная настройка (см. раздел 1.2).

### 1.1 Основная тема (Default Dark)

### Палитра (RGB565)

```
# Фоны
BG_BASE     #0A0C14   почти черный с синим подтоном — весь экран
BG_PANEL    #111827   панели, шапки
BG_CARD     #1C2540   карточки, пункты меню
BG_HIGHLIGHT #283255  выбранный пункт меню

# Акценты — смысловые
CYAN        #00D4FF   активное движение, прогресс, OK
GREEN       #00E87A   idle / всё хорошо
AMBER       #FFA020   предупреждение, частичное состояние
RED         #FF2840   ошибка, стоп, активный эндстоп
PURPLE      #9060FF   настройки, secondary action
WHITE       #FFFFFF   primary text, крупные цифры

# Текст и вспомогательное
TEXT_PRI    #FFFFFF
TEXT_SEC    #7A90BB   подписи, единицы измерения
TEXT_DIM    #3A4A66   disabled, placeholder
DIVIDER     #1E2E48   разделители
```

### 1.2 Высококонтрастный режим (High Contrast)

Включается в меню `Display → High Contrast: ON`. Переключает только цветовые токены — все остальные компоненты и экраны остаются прежними.

```
# Переопределения токенов в HC-режиме
BG_BASE      #000000   чистый черный
BG_PANEL     #000000
BG_CARD      #0A0A0A
BG_HIGHLIGHT #003060   ярко-синий фон выбора
TEXT_PRI     #FFFFFF
TEXT_SEC     #CCCCCC   вместо приглушенного голубого
TEXT_DIM     #888888
CYAN         #00FFFF   максимально яркий
GREEN        #00FF88
AMBER        #FFAA00
RED          #FF0000
```

В HC-режиме все тонкие градиенты и полупрозрачные оверлеи заменяются на solid-цвета, анимации остаются.

---

### 1.3 Правила использования цвета

| Состояние | Акцент | Прогресс-бар | Статус |
|---|---|---|---|
| IDLE | GREEN | GREEN dim | зеленый |
| MOVING | CYAN | CYAN (анимирован) | мигающие стрелки |
| HOMING | AMBER | AMBER пульс | spinner |
| ERROR | RED | RED flash | !!! |
| SLEEP | TEXT_DIM | — | луна |
| PARKING | AMBER→GREEN | — | |

## 2. Типографика

**Рекомендуемые шрифты** (конвертируются в GFX bitmap через fontconvert или LovyanGFX font tools):

| Уровень | Шрифт | Размер | Применение |
|---|---|---|---|
| XL | Roboto Mono Bold | 28–32px | Позиция (главный экран) |
| L | Roboto Mono Regular | 18–20px | Скорость, значения в редакторе |
| M | Roboto Condensed | 13–14px | Пункты меню, подписи |
| S | Roboto / system | 8px | Статусбар, подсказки кнопок |

**Важно:** моноширинный шрифт для чисел — цифры не скачут при изменении значения.

Единицы измерения (`steps`, `mA`, `%`) — TEXT_SEC, размер на 2–4px меньше цифры.

## 3. Компонентная библиотека

### Статусбар (верхняя строка, 12px)

```
┌────────────────────────────────────────┐
│ [BT●]  Camera Slider        [▊▊▊░] 11.2V │
└────────────────────────────────────────┘
```

- BT: иконка + цвет: CYAN (подключен) / TEXT_DIM (нет)
- Батарейка: 4 сегмента, цвет: GREEN→AMBER→RED по уровню
- Разделитель снизу: линия DIVIDER 1px

---

### Прогресс-бар позиции

```
  E1◄  ████████████████░░░░░░░░░░  ►E2
       ^              ^
    начало         текущая позиция (белый tick)
```

- Высота: 10px, скруглённые края 2px
- Фон: BG_CARD
- Заполнение: CYAN (движение) / GREEN (стоп)
- Маркер позиции: белая вертикальная линия 2px
- Маркер цели (GoTo): пунктир PURPLE
- Анимация: lerp `displayed += (actual - displayed) * 0.25` каждый кадр (≈50ms)
- Индикаторы эндстопов по краям: "E1◄" / "►E2", цвет RED если активен

---

### Индикатор направления (движущиеся стрелки)

Три стрелки в ряд, поочерёдно зажигаются в направлении движения:

```
BWD:  ◄◄◄  (анимация: ← ← ←)
FWD:  ►►►  (анимация: → → →)
```

- Период смены: 200ms
- Яркость: ярче → тусклее → тусклее (как "бегущий огонь")

---

### Пункт меню

```
┌─────────────────────────────────┐
│  [icon]  Label text    value  ▶ │   ← обычный
├─────────────────────────────────┤
│  [icon]  Label text    value  ▶ │   ← выбранный (BG_HIGHLIGHT + CYAN border left 2px)
└─────────────────────────────────┘
```

- Высота строки: 18px
- Иконка: 12×12, TEXT_SEC в обычном / CYAN в выбранном
- Стрелка ▶: только если есть подменю
- Скроллбар справа (2px, BG_HIGHLIGHT) если пунктов больше 6

---

### Редактор значения

```
┌─────────────────────────────────┐
│ ⚡ Motor Current                │
├─────────────────────────────────┤
│                                 │
│           800                   │   ← 28px, WHITE
│            mA                   │   ← 12px, TEXT_SEC
│                                 │
│  200 ───────────────── 1500     │   ← диапазон
│       ████████████░░░░░░        │   ← слайдер 8px
│                                 │
├─────────────────────────────────┤
│  [✕ CANCEL]          [✓ OK]   │
└─────────────────────────────────┘
```

- При изменении цифра коротко вспыхивает CYAN (50ms)
- Слайдер: фон DIVIDER, заполнение CYAN

---

### Подсказки кнопок (нижняя панель, 14px)

```
╔═══════╗              ╔═══════╗
║ ✕ BCK ║              ║ ✓ OK  ║
╚═══════╝              ╚═══════╝
```

- Скруглённые прямоугольники, 3px radius
- CANCEL: BG_CARD + TEXT_SEC
- OK/GO: BG_CARD + CYAN border
- STOP: RED fill + WHITE text
- HOME: AMBER

---

### Спиннер (хоминг, загрузка)

8-сегментный "часовой" спиннер 16×16 или 24×24:

```
  ╲ | ╱
  ─   ─     (один сегмент светлый, остальные тускнеют)
  ╱ | ╲
```

- Период полного оборота: 600ms
- Цвет: AMBER (хоминг), CYAN (GoTo)

## 5. Набор иконок

### Размеры и формат

Иконки существуют в **двух размерах** с разным подходом:

| Контекст | Размер | Формат | Цвета |
|---|---|---|---|
| Статусбар | 12×12 | 2-bit indexed (4 цвета) | фон прозрачный + 1–2 цвета |
| Главное меню (крупные плитки) | 32×32 | 4-bit indexed (16 цветов) | 2–3 цвета + фон |
| Подменю / список | 16×16 | 2-bit indexed | 2 цвета + фон |
| Кнопки-подсказки | 10×10 | 1-bit | монохром |

**Формат хранения:** массивы `uint8_t` в flash (PROGMEM). Для 32×32 с 4-bit: 512 байт на иконку — вполне приемлемо. Цвета задаются палитрой из 2–3 RGB565-значений + прозрачность через colorkey.

---

Главное меню отображает **3–4 пункта** на экране в виде плиток с большой иконкой и подписью. Иконки здесь — полноценные маленькие пиктограммы с 2–3 цветами.

## 6. Анимации

| Анимация | Триггер | Длительность | Описание |
|---|---|---|---|
| Screen slide | переход вперёд/назад в меню | 100ms | экран едет от правого/левого края |
| Menu scroll | поворот энкодера | 80ms | выделение lerp к новой позиции |
| Position bar lerp | каждые 50ms | continuous | `disp += (real - disp) * 0.25` |
| Moving arrows | MOVING состояние | loop 200ms | 3 стрелки "бегут" в направлении |
| Spinner | HOMING / loading | loop 600ms | 8 сегментов, один яркий |
| Value flash | изменение значения | 50ms | цифра вспыхивает CYAN |
| Error pulse | ERROR | loop 800ms | фон пульсирует красным |
| Sleep breathe | SLEEP | loop 3s | луна 40%↔100% brightness |
| Wake fade-in | выход из SLEEP | 200ms | яркость 0→100% (PWM backlight) |
| BT pulse | подключение | loop 1s | иконка пульсирует |

## 7. Раскладка дополнительных кнопок

К энкодеру добавляем 2 кнопки. Предлагаемая логика:

```
[BTN1]  [ENCODER BTN]  [BTN2]
  ↑           ↑            ↑
Quick       Select/      Menu/
Action      Confirm      Home
```

**BTN1 — Quick Action (контекстная):**
- Main screen: старт/стоп движения (аналог BLE F/B/S)
- В меню: выйти / назад (снимает нагрузку с энкодера)
- В редакторе: отмена

**BTN2 — Menu / Home:**
- Короткое нажатие: войти в меню / вернуться на главный экран
- Длинное нажатие (800ms): запуск хоминга (с подтверждением на экране)
- В ERROR: сброс ошибки

**Энкодер (кнопка):**
- В меню: select / confirm
- В редакторе: подтвердить значение
- На главном: войти в быстрый GoTo (ввод позиции энкодером)

Это убирает "длинное нажатие" энкодера как навигацию назад — интуитивнее и надёжнее.

## 8. Технические рекомендации

### Библиотека: LovyanGFX

```cpp
// Полный экранный буфер в PSRAM
LGFX_Sprite canvas(&display);
canvas.createSprite(160, 128);  // 40KB в PSRAM
// ... рисуем всё в canvas ...
canvas.pushSprite(0, 0);  // одна DMA-транзакция
```

Без артефактов рисования, без мерцания. На S3 с PSRAM работает отлично.

### Память

| Ресурс | Размер |
|---|---|
| Полный экранный буфер (RGB565) | 40 KB |
| Второй буфер (double-buffer) | 40 KB |
| Иконки 32×32 × 4-bit (13 шт меню) | ~7 KB |
| Иконки 16×16 × 2-bit (13 шт подменю) | ~1 KB |
| Иконки 12×12 статусбар (8 шт) | <1 KB |

| Шрифт 14px sans | ~4 KB |
| Шрифт 8px | ~1 KB |
| **Итого (без PSRAM)** | **~50 KB heap** |
| **С PSRAM** | без ограничений |

### Рекомендация по PSRAM

- Без PSRAM: работает, но буфер придётся делать половинным (160×64) и обновлять в два прохода
- С PSRAM (8MB QSPI на S3): полный буфер, двойная буферизация, можно хранить sprite-атлас иконок
